The Three-Point Takeover

By Jason Miller · NBA regular-season player box scores, 1994-95 to 2025-26

This report covers {{n(R.head.kept_rows)}} player appearances from {{n(R.head.games)}} regular-season games ({{R.head.first_date}} to {{R.head.last_date}}). The clearest change is the shot itself: the average player now attempts {{f(R.head.tpa_last,1)}} threes a game, up from {{f(R.head.tpa_first,1)}} in 1995-96, and threes are {{pct(R.head.tpar_last)}} of all shots, up from {{pct(R.head.tpar_first)}}. Scoring efficiency rose with it, while free throws, offensive rebounds and the old post-player roles faded. Home-court advantage is still real but has weakened. DATA

About the data set

Where it comes from

An NBA player box-score file named PlayerStatistics.csv (player-level game logs) that I downloaded, then trimmed to the regular season. It is not stored in this repository because it is {{n(R.head.raw_rows)}} rows and over 100 MB, past GitHub's file limit. scripts/build_data.py reads it and writes the small summary files this site loads.

What one row is

One row is one player in one game for one team: their minutes, points, assists, rebounds, steals, blocks, shots made and attempted, turnovers and fouls. The source names its columns ppg, apg and so on, but they hold single-game values, not averages.

Rows dropped

  • {{n(R.head.dropped_nan)}} rows with no minutes recorded. Nearly all are players who did not play (coach's decision, injury, rest). They have no stats to average, and keeping them would pull every per-appearance rate down.
  • {{n(R.head.dropped_zero)}} rows with exactly 0 minutes. Same reason. A few hundred of these show points anyway, which is a recording error, so they are dropped too.
  • That leaves {{n(R.head.kept_rows)}} rows, {{pct(R.head.kept_rows/R.head.raw_rows)}} of the file.

Other choices: seasons are labelled by the year they start (games from September on belong to that year's season). The first season, 1994-95, begins in December 1994 in this file, so it is partial and I use 1995-96 as the starting point for comparisons. The file is missing DNP rows before 1996, but since those are dropped anyway, this does not change any rate. Teams are grouped by franchise: Bobcats with Hornets, SuperSonics with Thunder, New Jersey with Brooklyn, Vancouver with Memphis, Bullets with Wizards, and the original Charlotte Hornets (to 2001-02) with the New Orleans Pelicans.
